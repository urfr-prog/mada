📝 ADAM v31 — Dual State + Inherit Respawn

Architecture :

Chaque demi-face est une entité indépendante (id, pileIcon, faceIcon, state).

Chaque cellule est un conteneur (topHalfId, bottomHalfId, rotation, flipped).

halfFaces[id] = { id, pileIcon, faceIcon, state }
cells[0..8]   = { topHalfId, bottomHalfId, rotation, flipped } | null

Contrôles :

Tap moitié droite : rotation +90° (horaire)

Tap moitié gauche : rotation -90° (antihoraire)

Drag horizontal : tapis roulant (déplace la ligne)

Swipe vertical : retourne le domino (pile/face)
